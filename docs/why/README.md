# Why vincent is awesome

The rest of the documentation explains what vincent does and how to use it.
This section is about why it was created: the repeated work, practical problems,
and lessons that made a durable workflow orchestrator feel necessary.

These are not feature announcements. They are the stories behind the product
and the principles that continue to shape it.
